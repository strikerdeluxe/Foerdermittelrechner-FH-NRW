# Fördermittel-Verteilungsrechner – Web-Version

Dieser Branch enthält die über GitHub Pages veröffentlichte Web-Version des Fördermittelrechners:
eine einzelne HTML-Datei (`index.html`), die vollständig im Browser läuft. Die Anwendung liegt verschlüsselt
in der Datei und öffnet sich erst nach Eingabe des Passworts. ExcelJS und die Schriften sind eingebettet,
die Seite lädt nichts von anderen Servern nach. Eingegebene Daten werden nicht übertragen.

Quellcode und Build-Skript liegen im Branch `main` im Ordner `web/`.
